- Build and run: [BUILD.md](BUILD.md).
- `./gradlew build` passes before every commit and PR.
- Plugin Hub restrictions: [hub-restrictions.md](.claude/rules/hub-restrictions.md).
- Client thread, no `new` client services: [runelite-api.md](.claude/rules/runelite-api.md).
- Style: [java-style.md](.claude/rules/java-style.md).
- Commits carry source only, no build artifacts; reformatting never mixed with feature changes.
- A change is done only after it is verified in-game.
- AI agent guidance: [.claude/](.claude/CLAUDE.md).
