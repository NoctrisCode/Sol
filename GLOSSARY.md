# Sol

Sol is Lost Legion's RuneLite plugin for clan engagement.

## Language

**Lost Legion**:
A RuneScape clan. Owns this plugin and the other clan tools.
_Avoid_: LL (in prose), the guild

**Sol**:
This plugin, displayed as "Lost Legion: Sol". The name comes from a RuneScape boss.
_Avoid_: the extension, the mod

**Boss name**:
The naming convention for Lost Legion tools: each one is named after a RuneScape boss.
